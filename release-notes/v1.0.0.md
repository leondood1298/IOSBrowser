The last planned milestone: VLC playback, a share extension, and polish.

**Files**
- `Browser-1.0.0.ipa`: the app, unsigned. Sign and install it with Signulous (install over 0.8.0 to keep everything).
- `Browser-1.0.0-with-share-extension.ipa`: the same app with its share extension. Try it if you want "Browser" in the share sheet; if Signulous can't sign it or it fails to install, use the plain IPA.
- `BrowserProbe-1.0.0.ipa`: optional test copy that asks for the default-browser entitlement.

**New**
- **VLC player** for what the system player can't open: MKV, WebM, AVI, FLV, WMV, MPEG-TS, Ogg, WMA and more.
  - Play and pause, skip 10 seconds (buttons, double-tap the sides, or the arrow keys), scrub, change the speed, and pick audio and subtitle tracks.
  - The folder's next file plays after this one, and each file continues where you left it.
- **Share extension** (in the second IPA): in any app's share sheet, Browser can open the link in a new or private tab, download it, or search for shared text.
- A short **tour** on first launch.
- A new **app icon**.

**Fixed**
- The media list showed a streaming video twice (the stream and the quality the page's player loaded); it's listed once now.

**Device checklist**
- [ ] Install `Browser-1.0.0.ipa` over 0.8.0: everything is still there, and the tour appears once.
- [ ] Download an MKV or WebM video and open it in Files: it plays in the VLC player, with sound. Try the subtitle menu on a file that has subtitles.
- [ ] Optional: install `Browser-1.0.0-with-share-extension.ipa`. In Safari, share a page and choose Browser › Open in Browser; the page opens in a new tab. Try Download with Browser on a file link.
