The file manager, Aloha style.

**Files**
- `Browser-0.5.0.ipa`: the app, unsigned. Sign and install it with Signulous (install over 0.4.0 to keep your tabs and downloads).
- `BrowserProbe-0.5.0.ipa`: optional test copy that asks for the default-browser entitlement.

**New**
- **Files** (page menu › Files, or the Downloads list):
  - List or grid with thumbnails and sizes.
  - Sort by name, date, size, type or length, and search all folders.
  - The header shows how much space the browser's files use and how much is free on the iPad.
- Long-press a file for: open, share or Open In…, rename, duplicate, move, copy, compress or extract, info, Save to Photos, export to the Files app, Open Source Page, delete.
- **Select** several files to share, move, copy, delete or compress them together.
- **Archives:**
  - Make and open ZIP files.
  - Open 7-Zip, RAR (including RAR5 and password-protected archives), TAR, GZip, BZip2 and XZ.
  - Extracting shows progress and creates a folder.
- **Bin:** deleted files stay for 30 days and can be put back. You can turn the Bin off in Settings.
- **Bring files in:**
  - From the Files app or Photos.
  - With "Open in Browser" from other apps.
  - By dragging them onto a folder.

**Device checklist**
- [ ] Install over 0.4.0 with Signulous: your downloads are still listed and in Files.
- [ ] Open Files from the page menu. Switch to the grid, sort by size, and search for a file.
- [ ] Select two files and compress them into a ZIP, then extract the ZIP.
- [ ] Extract a RAR or 7z archive. If you have a password-protected one, check that it asks for the password.
- [ ] Delete a file, open the Bin and put it back.
- [ ] Import a photo from Photos, and share a file from another app with "Open in Browser".
- [ ] Save a downloaded image to Photos from its menu.
