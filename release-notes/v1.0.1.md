Fixes 1.0.0, which didn't launch on an iPad: the VLC framework was left out of the app.

**Files**
- `Browser-1.0.1.ipa`: the app, unsigned. Sign and install it with Signulous (install over 0.8.0 to keep everything). It's bigger than before (about 17 MB) because it now includes VLC.
- `Browser-1.0.1-with-share-extension.ipa`: the same app with its share extension ("Browser" in the share sheet). If Signulous can't sign it or it fails to install, use the plain IPA.
- `BrowserProbe-1.0.1.ipa`: optional test copy that asks for the default-browser entitlement.

Everything in 1.0.0 is here too (see its notes): the VLC player for MKV, WebM, AVI and more, the share extension, the first-launch tour and the new icon.

**Fixed**
- The app launches: the VLC framework is now inside it. Building an IPA now fails if a framework the app needs is missing, so this can't slip through again.

**Device checklist**
- [ ] Install `Browser-1.0.1.ipa` over 0.8.0: it launches, everything is still there, and the tour appears once.
- [ ] Download an MKV or WebM video and open it in Files: it plays in the VLC player, with sound.
- [ ] Optional: install `Browser-1.0.1-with-share-extension.ipa`. In Safari, share a page and choose Browser › Open in Browser; the page opens in a new tab.
