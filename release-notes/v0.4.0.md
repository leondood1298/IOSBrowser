The download manager, Aloha style.

**Files**
- `Browser-0.4.0.ipa`: the app, unsigned. Sign and install it with Signulous (install over 0.3.0 to keep your tabs).
- `BrowserProbe-0.4.0.ipa`: optional test copy that asks for the default-browser entitlement.

**New**
- Downloads start from file links, from "Download Linked File" in a link's long-press menu, and from **+ › Download from URL** (filled from the clipboard).
- Before a download starts, a sheet shows its name, size and type and lets you rename it or pick the folder. You can turn the sheet off in Settings.
- The ring in the toolbar shows overall progress and opens the Downloads list:
  - Sections for Active, Completed and Failed downloads, with speed, time left and "X of Y".
  - Pause, resume, retry, cancel, open, share, show in Files, rename and delete.
  - When a link has expired, the row says so and offers **Open Source Page**.
- Downloads from normal tabs carry on in the background after you leave the app, and big files download in up to 8 parts at once (Settings › Downloads).
- While downloads run, a Live Activity shows their progress on the Lock Screen and in the Dynamic Island area. It also keeps the app working in the background.
- When a download finishes, a notification and the app badge tell you.
- Files are sorted into Downloads, Videos, Music, Pictures and Documents by type (or all into one folder), visible in the Files app under Browser.
- Private-tab downloads stay out of the saved list and are forgotten when you erase.

**Not yet**
- There's no limit on how many downloads run at once; they all start right away.

**Device checklist**
- [ ] Install over 0.3.0 with Signulous: your tabs are still there.
- [ ] Download a large file (100 MB or more). The ring and the Downloads list show progress, speed and time left. Pause it, then resume it.
- [ ] Start a large download and go to the Home Screen. A Live Activity shows the progress, and it keeps going with the screen locked.
- [ ] Leave the app during a download from a normal tab and wait: the download finishes, and a notification appears.
- [ ] Open the Files app › On My iPad › Browser › Downloads: the file is there.
- [ ] Long-press a link to a file and choose Download Linked File.
- [ ] + › Download from URL with a link copied to the clipboard.
