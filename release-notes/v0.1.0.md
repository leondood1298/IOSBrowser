First build of the pipeline: a minimal single-tab browser that proves the build → sign → install loop.

**Files**
- `Browser-0.1.0.ipa`: the app, unsigned. Sign and install it with Signulous.
- `BrowserProbe-0.1.0.ipa`: optional test copy that asks for the default-browser entitlement.

**Device checklist**
- [ ] The app installs through Signulous and opens.
- [ ] Typing an address (for example `wikipedia.org`) loads it; typing words searches Google.
- [ ] Back, forward and reload work, and swiping from the edge goes back.
- [ ] The Files app shows **On My iPad › Browser** with Downloads, Videos, Music, Pictures and Documents.
- [ ] Note whether Signulous changed the bundle ID or app name.
- [ ] Optional: install Browser Probe and check Settings › Apps › Default Browser App for "Browser Probe".
